# Transformer Zero

A fine-tuned decoder Transformer that matches patient descriptions to individual clinical-trial inclusion/exclusion criteria, cites the supporting patient sentences, and implements KV-cached decoding, tiled online-softmax attention and speculative decoding from scratch.

Built for Generative AI Assignment 2 on the [TrialGPT Criterion Annotations](https://huggingface.co/datasets/ncbi/TrialGPT-Criterion-Annotations) dataset.

> **Educational screening prototype only. Not a clinical enrollment decision tool.**
