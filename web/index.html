    How to read a result

    five outcomes, one per criterion
    IncludedThe note shows the patient meets this inclusion rule.
    Not included / ExcludedThe patient fails an inclusion rule, or an exclusion rule applies — a likely stop.
    Not excludedAn exclusion rule was checked and does not apply — the patient passes it.
    Not enough informationThe note doesn't say either way. The model declines to guess.
    Not applicableThe rule doesn't apply to this patient — a pregnancy criterion for a man, say.

    Evidence, not vibes

    Every decision comes with the sentence numbers it rests on. Hover a criterion and those sentences light up in the note, so you can check the model's reasoning instead of trusting it. A decision with no evidence is itself a signal — usually "not enough information."

    How it decides

    1
    Label and cite.

    The fine-tuned model reads one criterion and the note, returns a label, and lists the sentence numbers that justify it — as strict JSON, so nothing is hand-waved.

    2
    Explain from the citation.

    The same model, with fine-tuning switched off, writes a plain-English reason using only the cited sentences — so the explanation can't drift from the evidence.

    3
    Roll up a verdict.

    A simple rule combines the per-criterion labels into an overall read: eligible, needs more information, or likely not eligible.

    How accurate is it?

    ~76%criterion-level agreement with expert physicians, held-out test set

    That sounds modest until you see the ceiling: the dataset's own GPT-4 labels agree with the experts only ~90% of the time, and even that is inflated, because the expert labels were made by correcting GPT-4. A 4-billion-parameter open model, run on a single GPU, lands close behind — and never produces malformed output.

    Where it slips, it slips cautiously: it leans toward "not enough information" or "not excluded" when a human would commit. It under-calls exclusions more than it invents them — the safer direction for a screening aid a person reviews.
